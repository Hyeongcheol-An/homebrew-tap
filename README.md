# Hyeongcheol-An/homebrew-tap

Homebrew casks maintained by [Hyeongcheol-An](https://github.com/Hyeongcheol-An).

```bash
brew tap Hyeongcheol-An/tap
brew trust Hyeongcheol-An/tap      # Homebrew 7+ asks you to trust third-party taps once
brew install --cask mobalt
```

| Cask | App |
|---|---|
| `mobalt` | [MobAlt](https://github.com/Hyeongcheol-An/MobAlt) — MobaXterm-style SSH / SFTP / terminal workbench for macOS |

`Casks/mobalt.rb` is updated automatically by MobAlt's release workflow.
